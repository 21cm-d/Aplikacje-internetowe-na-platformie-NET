BAZA KLIENTÓW - ASP.NET CORE MVC

Wymagane: .NET 8 SDK

Uruchomienie:
1. Otwórz terminal w folderze BazaKlientow.
2. Wpisz: dotnet restore
3. Wpisz: dotnet run
4. Otwórz adres pokazany w terminalu, np. http://localhost:5000

Baza klienci.db tworzy się automatycznie przy pierwszym uruchomieniu.
Projekt umożliwia dodawanie, edycję, usuwanie, podgląd i wyszukiwanie klientów.
